# What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript code to run outside the browser.

It enables developers to build server-side applications and execute JavaScript programs directly on a computer or server.

---

# Why Do We Need Node.js?

Node.js is required because it allows us to:

- Run JavaScript outside the browser.
- Build backend applications.
- Run React and Next.js during development.
- Install packages using npm.
- Develop full-stack web applications.

Without Node.js, frameworks like React and Next.js cannot run on our local computer.

---

# What is npm?

npm stands for **Node Package Manager**.

It is automatically installed with Node.js.

It helps developers install, update, and manage packages used in a project.

Examples of packages:

- React
- Next.js
- Tailwind CSS
- Prisma
- Axios

Example:

```bash
npm install react
```

---

# JavaScript vs Node.js

| JavaScript | Node.js |
|------------|----------|
| Programming language | JavaScript runtime environment |
| Runs inside a browser | Runs outside the browser |
| Creates interactive websites | Runs JavaScript applications |
| Cannot manage packages by itself | Includes npm for package management |

# Interview Questions

## What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript code to run outside the browser.

---

## Why do we need Node.js?

Node.js allows developers to run JavaScript outside the browser, build backend applications, and use frameworks like React and Next.js.

---

## What is npm?

npm (Node Package Manager) is the default package manager for Node.js. It helps install and manage project dependencies.

---

## Difference between JavaScript and Node.js?

JavaScript is a programming language used to create interactive web applications.

Node.js is a runtime environment that executes JavaScript outside the browser.
