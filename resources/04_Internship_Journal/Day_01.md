# Knowledge Gained

## Version Control

A system that records changes made to files over time and allows developers to restore previous versions when needed.

---

## Git

A Distributed Version Control System (DVCS) used to track project changes and maintain version history.

---

## GitHub

An online platform used to host Git repositories and collaborate with other developers.

---

## Repository

A project that is tracked by Git.

---

## Commit

A snapshot of a project's meaningful state along with a message describing what changed.

---
